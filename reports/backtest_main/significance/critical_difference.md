# critical_difference

Average rank per model; models joined by a heavy horizontal bar are statistically indistinguishable at alpha=0.05 (Nemenyi post-hoc, CD = 0.249). N = 2,950 series. CD shrinks as sqrt(1/N), so at this sample size nearly any rank gap clears it -- statistical separability here is not the same as a difference worth acting on. The test also assumes the compared forecasts are independent, which is violated for series nested in a hierarchy.
