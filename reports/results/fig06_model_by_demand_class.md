# fig06_model_by_demand_class

WAPE per model within each Syntetos-Boylan-Croston demand class. Colour is normalised WITHIN each column, because absolute WAPE differs by roughly an order of magnitude between dense and sparse segments; a globally-scaled heatmap would only restate which segment is hard. Boxed cells are the best model in that class. Best single model in the sparse quadrants: INTERMITTENT -> adida, LUMPY -> adida. Classes here are the full-history EDA classification, so a series can sit in a different class than the router gave it at an origin; the router's own per-segment score against the best single model is `routing_vs_best_single.csv` (README router table).
