# fig07_model_by_level

WAPE per model at each of the six aggregation levels, forecasts summed bottom-up. Colour normalised within each column so the comparison is between models at a level, not between levels. Best WAPE improves from 75.2 at item-store to 5.8 at total, a 92% reduction from aggregation alone. Error cancels as series are aggregated, so a model's rank can change with the level a decision is actually taken at.
